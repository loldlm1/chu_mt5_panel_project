# Triage labels

| Canonical role | GitHub label | Meaning |
| --- | --- | --- |
| needs-triage | needs-triage | Needs evaluation |
| needs-info | needs-info | Requires information |
| ready-for-agent | ready-for-agent | Specified and unblocked for implementation |
| ready-for-human | ready-for-human | Requires user action (including MetaEditor compile or acceptance) |
| wontfix | wontfix | Intentionally not implemented |

When the GitHub integration cannot create a missing label, preserve the canonical status as text on the issue or PR instead of inventing label creation.
